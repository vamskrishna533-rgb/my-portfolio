\# AI Writing Workflow — Draft, Critique \& Revise



\## Overview



This project is a repeatable AI writing workflow that helps me improve real writing while keeping my original meaning and personal voice.



The workflow takes writing through four main stages:



Draft → Critique → Revise → Final Review



The goal is to make writing clearer, more professional, and more effective without adding unsupported facts or changing what I actually mean.



\## Who It Is For



This workflow is mainly useful for students and early-career professionals who want help improving:



\- LinkedIn messages

\- Professional emails

\- Project descriptions

\- Personal or career writing

\- Portfolio bios



\## How It Works



Input → Draft → Critique → Revise → Final Review → Final Output



\### 1. Draft



The AI creates a first draft from the writing I provide. It is instructed to keep my meaning and personal voice and not invent facts, achievements, or experiences.



\### 2. Critique



The AI reviews the draft for clarity, structure, grammar, tone, credibility, and effectiveness.



\### 3. Revise



The draft is improved using the critique while keeping the original meaning and voice.



\### 4. Final Review



The final version is checked for accuracy, clarity, grammar, tone, consistency, and unsupported claims.



Human review is still required before using the final output.



\## Example Uses



I tested the workflow on five real writing inputs:



1\. LinkedIn message

2\. Professional email

3\. Lyft project description

4\. ACCA preparation paragraph

5\. Portfolio bio



\## V2 Evaluation Results



I tested the workflow on five real inputs and compared the time taken manually with the workflow execution time.



| Run | Manual Time | Workflow Time |

|---|---:|---:|

| LinkedIn Message | 2 min | 10 sec |

| Professional Email | 2 min | 12 sec |

| Lyft Project Description | 3.5 min | 12 sec |

| ACCA Paragraph | 29 min | 17 sec |

| Portfolio Bio | 20 min | 22 sec |

| Total | 56.5 min | 73 sec (1.22 min) |



The workflow execution time was approximately 1.22 minutes, compared with 56.5 minutes of manual work for the five tests.



The estimated time saved before setup was about 55.28 minutes.



The workflow setup itself took about 120 minutes, so the estimated net time saved after setup was -64.72 minutes for this initial evaluation.



\## Limitations



The workflow has several limitations:



\- It cannot create missing facts, project details, results, numbers, or personal experiences.

\- Short or incomplete inputs limit how much the workflow can improve the writing.

\- AI can sometimes make wording more confident than my original meaning.

\- I still need to check facts, names, numbers, claims, tone, and whether the final version represents my actual experience.

\- Human judgment is required before using the final output.



\## What I Built With AI



I built this workflow using AI assistance to help design and test the writing stages, prompts, critiques, and revisions.



I checked the outputs myself for accuracy, meaning, personal voice, unsupported claims, and whether the final writing represented my actual experience.



AI helped with the writing and workflow process, but I remained responsible for the final decisions and verification.



\## Final Result



The workflow successfully ran end-to-end on five real writing inputs using the four stages:



Draft → Critique → Revise → Final Review



It made the writing and editing process faster during the tests, while showing that human review is still important for accuracy, personal voice, and missing information.
